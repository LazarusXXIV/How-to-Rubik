魔方入门基础课 · 层先法整体思路

1. 认识魔方的三种块

  • 中心块（6 个，单色）：相对位置永远固定，决定了每一面最终应该还原成什么颜色（如顶面紫色、底面黄色）。
  • 棱块（12 个，双色）：位于每条边中间，只能在棱块位置间移动。
  • 角块（8 个，三色）：位于八个顶点，只能在角块位置间移动。

2. 读懂国际标准公式字母

U / D顶层（紫） / 底层（黄）顺时针 90° F / B前层（绿） / 后层（蓝）顺时针 90° R / L右层（红） / 左层（橙）顺时针 90° '（撇号）表示该面逆时针旋转 90°（如 R'） 2（数字 2）表示该面连续旋转 180°（如 U2）

3. 整体还原心法（层先法 7 步）

由下至上逐层封顶：①底层十字 → ②底层四角 → ③中层四棱 → ④顶层十字 → ⑤顶面全紫 → ⑥顶层四角 → ⑦顶层四棱。所有中后期公式的核心原理都是「临时借位 → 换块/翻色 → 原路归位」，绝不破坏已经拼好的下层。

操作说明

鼠标 / 触控

  • 拖动魔方表面：沿拖拽方向拧动对应层 90°
  • 拖动空白区域：360° 旋转观察视角
  • 滚轮 / 双指捏合：缩放视图距离
